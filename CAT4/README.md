# INTERFACE USING KEYPAD MATRIX, LEDS AND SEVEN-SEGMENT DISPLAY 

Whenever a valid key is pressed:  
- Display the key value on the seven-segment display
- Execute the corresponding LED function

| KEY PRESS | LED OPERATION | SEVEN SEGMENT DISPLAY |
|---|---|---|
| 1 | 1 | LED1 ON |
| 2 | 2 | LED2 ON |
| 3 | 3 | LED3 ON |
| 4 | 4 | LED4 ON |
| 5 | 5 | Running LED Pattern |
| 6 | 6 | Alternate LEDs |
| 7 | 7 | Binary Counter |
| 8 | 8 | All LEDs Blink |
| 9 | 9 | All LEDs OFF |
| 0 | 0 | Reset System |
